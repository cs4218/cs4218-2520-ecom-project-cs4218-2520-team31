

# n8n Workflow Setup

This folder contains the **n8n workflow JSON** used for AI-driven testing.

---

## 1. Start ngrok

Run the following command:

```bash
ngrok http 5678
```

This exposes the local n8n instance to the internet so GitHub webhooks can reach it.

You will get a URL like:

```
https://xxxx.ngrok-free.app
```

Copy this URL. This will be your `<YOUR_NGROK_URL>`.

---

## 2. Start n8n with Docker

Replace `<YOUR_NGROK_URL>` with your ngrok URL:

```bash
docker run -it --rm --name n8n -p 5678:5678 -v C:\n8n-data:/home/node/.n8n -e WEBHOOK_URL=<YOUR_NGROK_URL> -e N8N_BASIC_AUTH_ACTIVE=true -e N8N_BASIC_AUTH_USER=admin -e N8N_BASIC_AUTH_PASSWORD=password n8nio/n8n
```

Example:

```bash
-e WEBHOOK_URL=https://xxxx.ngrok-free.app
```

This starts n8n locally on port **5678** and stores workflow data in **C:\n8n-data**.

---

## 3. Open n8n

Go to:

```
<YOUR_NGROK_URL>
```

Login with:

Username: `admin`
Password: `password`

---

## 4. Import the Workflow JSON

In n8n:

* Click **Import from File**
* Select the workflow JSON file
* Save the workflow

---

## 5. Configure Credentials

Set up the required credentials in n8n:

### GitHub API

Create GitHub token from:

```
https://github.com/settings/tokens
```

Add credential in n8n:

* Go to **Credentials**
* Add **GitHub**
* Paste token

---

### Gemini API

Create Gemini API key from:

```
https://aistudio.google.com/app/apikey
```

Add credential in n8n:

* Go to **Credentials**
* Add **HTTP Request / Gemini**
* Paste API key

---

## 6. Activate the Workflow

After importing and configuring credentials:

* Activate workflow
* Copy webhook URL generated by n8n
* Add webhook to GitHub repository

GitHub → Settings → Webhooks → Add webhook

---

## 7. Workflow Purpose

This workflow is used for AI-driven testing support. It:

* Detects pull request changes from GitHub
* Retrieves changed files
* Sends files to Gemini AI
* Prompts AI to review changes
* Generates AI comments for modified files

---

## 8. Stop n8n

To stop n8n:

```bash
Ctrl + C
```

in the terminal where Docker is running.
